# Lumina — Minimalist Laser & Mirror Puzzle

Lumina is a sleek, browser-based laser puzzle and physics sandbox game built from scratch using HTML5 Canvas, Tailwind CSS, and vanilla JavaScript. Direct glowing beams of light across an interactive grid using rotatable mirrors, beam splitters, and blockers to illuminate target nodes.

---

## ✨ Features

- **Raycasting Laser Engine:** Real-time reflection and beam-splitting calculations across custom grid coordinates.
- **5 Campaign Levels:** Progressive difficulty curve introducing new mechanics like dual reflections, splitters, and obstacles.
- **Custom Sandbox Mode:** Design your own levels using the live toolset (Mirrors, Splitters, Blockers, Targets, and Eraser).
- **Web Audio API Sound FX:** Satisfying audio feedback on rotations, wins, and clicks.
- **Modern Dark Burgundy Theme:** Built with Tailwind CSS, dark glassmorphism cards, and neon glow effects.

---

## 🚀 Getting Started & Local Setup

Since Lumina is a single-file application (`index.html`), no build steps, bundlers, or package installations are required!

1. Clone or download the repository to your local machine.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).

---

## 📦 Pushing to GitHub

To push this project to a new GitHub repository, open your terminal in the project directory and run the following commands:

```bash
# Initialize git repository
git init

# Add the project files
git add index.html README.md

# Commit changes
git commit -m "Initial commit: Lumina minimalist laser puzzle game"

# Link your remote repository (replace with your repo URL)
git branch -M main
git remote add origin https://github.com/your-username/lumina-laser-puzzle.git

# Push to GitHub
git push -u origin main
```
